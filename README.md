# CASHVERSE v1

CASHVERSE is a simple browser-based cash-in/cash-out ledger for small Philippine stores.

## Version 1
- GCash and Maya float balances
- Cash-in and cash-out recording
- Editable fee rules
- Fee can be added on top or deducted from the customer amount
- Completed transactions automatically update wallet float
- Pending/failed transactions do not affect float
- Manual wallet adjustments
- Transaction history
- Daily earnings summary
- Owner login
- PostgreSQL-ready for Railway

This app is bookkeeping software only. It does not connect to or move funds inside GCash or Maya. Always verify the real transaction in the official wallet app before marking a transaction completed.
